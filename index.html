01 / DEFINITION

AI Hallucination คืออะไร

ปรากฏการณ์ที่แบบจำลองปัญญาประดิษฐ์เชิงรู้สร้าง (Generative AI) สร้างเนื้อหาที่ดูมีความสมเหตุสมผลในเชิงภาษา แต่ไม่ถูกต้องตามข้อเท็จจริง ไม่สอดคล้องกับแหล่งข้อมูลอ้างอิง หรือเป็นข้อมูลที่ไม่มีอยู่จริง เกิดขึ้นได้แม้ในแบบจำลองที่มีประสิทธิภาพสูง เพราะกลไกการทำงานคือการทำนายลำดับคำที่มีความน่าจะเป็นสูงสุด มิใช่การตรวจสอบความจริงจากฐานความรู้ที่ตายตัว

02 / VARIABLES

ปัจจัยความเสี่ยงทั้งสี่

แบบจำลองกำหนดตัวแปรหลัก 4 ตัว โดยทุกตัวแปรอยู่ในช่วง [0, 1] — คลิกที่การ์ดเพื่อดูผลกระทบต่อ H

U
DATA UNCERTAINTY
ความไม่แน่นอนของข้อมูลที่แบบจำลองมีอยู่เกี่ยวกับหัวข้อที่ถูกถาม ค่าสูง = ข้อมูลคลุมเครือ ขัดแย้งกันเอง หรือไม่เพียงพอ
▲ เพิ่มความเสี่ยง H
C
QUESTION COMPLEXITY
ความซับซ้อนของคำถามหรือภารกิจ ครอบคลุมโครงสร้างคำถาม จำนวนขั้นตอนการให้เหตุผล และความเฉพาะทาง
▲ เพิ่มความเสี่ยง H
P
PROMPT QUALITY
คุณภาพของ Prompt ที่ผู้ใช้ป้อนให้แบบจำลอง ครอบคลุมความชัดเจน ความเฉพาะเจาะจง และโครงสร้างของคำสั่ง
▼ ลดความเสี่ยง H
B
CONTEXT
ปริมาณและความเกี่ยวข้องของบริบทหรือข้อมูลสนับสนุนที่แบบจำลองได้รับ เช่น เอกสารอ้างอิง หรือข้อมูลจาก Retrieval
▼ ลดความเสี่ยง H
03 / EQUATION

Mathematical Model

เนื่องจากค่าความเสี่ยง H ต้องอยู่ในช่วง [0, 1] แบบจำลองนี้เลือกใช้ฟังก์ชันโลจิสติก (Logistic Function) ซึ่งให้ผลลัพธ์อยู่ใน (0, 1) เสมอ มีรูปทรง Sigmoid และสามารถรวมตัวแปรหลายตัวผ่านตัวแปรกลาง Z ได้

H(U,C,P,B) คือความเสี่ยงของ Hallucination · Z คือตัวแปรเชิงเส้นรวม (Linear Combination)
สัมประสิทธิ์ความหมายทิศทาง
aน้ำหนักผลกระทบของความไม่แน่นอนของข้อมูล Uบวก (+)
bน้ำหนักผลกระทบของความซับซ้อนของคำถาม Cบวก (+)
cน้ำหนักผลกระทบของคุณภาพ Prompt Pลบ (−)
dน้ำหนักผลกระทบของบริบท Bลบ (−)
kค่าคงที่ปรับฐาน (Baseline Constant) — เลื่อนตำแหน่งเส้นโค้งบนแกน Zคงที่
ข้อควรระวัง — พารามิเตอร์สาธิต a = 8, b = 4, c = 3, d = 2, k = −5 เป็นค่าที่ สมมติขึ้นเพื่อสาธิตพฤติกรรมของแบบจำลอง ไม่ใช่ค่าที่ได้จากการฝึกฝนหรือวัดจากระบบ AI จริงแต่อย่างใด (a มากที่สุดสะท้อนว่า Data Uncertainty มีอิทธิพลสูงสุด, k เลื่อนจุดสมดุลของเส้นโค้งให้เหมาะกับช่วง U ∈ [0,1])

04 / GRAPH

Logistic Risk Curve

แกน X แทนค่า U (Data Uncertainty) และแกน Y แทนค่า H (Hallucination Risk) — เส้นโค้งทั้ง 4 เส้นคือ 4 สถานการณ์ ที่ตรึงค่า C, P, B คงที่ต่างกัน วางเมาส์บนกราฟหรือรายการด้านขวาเพื่อไฮไลต์แต่ละกรณี

05 / SCENARIO MATRIX

สี่สถานการณ์เชิงแนวคิด

คลิกที่การ์ดแต่ละใบเพื่อดูสมการ Z และ H ที่ได้จากการแทนค่า C, P, B ตามรายงาน

CASE 1 · BEST CASE

ต่ำ + คุณภาพ Prompt สูง + บริบทเพียงพอ

C = 0.2P = 0.9B = 0.9
Z₁ = 8x − 8.7
สถานการณ์ที่เอื้ออำนวยต่อการลดความเสี่ยงมากที่สุด เนื่องจากค่าคงที่ใน Z ติดลบมาก ต้องอาศัยค่า U ที่สูงมากจึงจะทำให้ H เข้าใกล้ค่าสูง (ทนทานสูงสุด)
CASE 2

สูง + คุณภาพ Prompt สูง + บริบทเพียงพอ

C = 0.9P = 0.9B = 0.9
Z₂ = 8x − 5.9
แม้ Prompt คุณภาพสูงและบริบทเพียงพอเช่นเดียวกับ Case 1 แต่ความซับซ้อนของคำถามที่สูงขึ้นทำให้เส้นโค้งเลื่อนไปทางซ้าย — มีความเสี่ยงสูงกว่าที่ค่า U เดียวกัน
CASE 3

ต่ำ + คุณภาพ Prompt ต่ำ + บริบทไม่เพียงพอ

C = 0.2P = 0.2B = 0.2
Z₃ = 8x − 5.2
แม้คำถามไม่ซับซ้อน แต่คุณภาพ Prompt ต่ำและบริบทไม่เพียงพอทำให้เส้นโค้งเลื่อนไปทางซ้ายมากกว่า Case 1–2 แสดงว่าปัจจัย Prompt และบริบทมีบทบาทสำคัญไม่น้อยไปกว่าความซับซ้อนของคำถาม
CASE 4 · WORST CASE

สูง + คุณภาพ Prompt ต่ำ + บริบทไม่เพียงพอ

C = 0.9P = 0.2B = 0.2
Z₄ = 8x − 2.4
สถานการณ์ที่มีความเสี่ยงสูงที่สุด เนื่องจากทุกปัจจัยส่งผลเพิ่มความเสี่ยงพร้อมกัน แม้ U จะยังไม่สูงมาก H ก็สามารถเข้าใกล้ค่าสูงได้อย่างรวดเร็ว (จุดวิกฤต Z=0 ที่ x = 2.4/8 = 0.3)
06 / INTERPRETATION

ระดับความเสี่ยง

เกณฑ์เชิงแนวคิดสำหรับตีความค่า H ที่ได้จากแบบจำลอง

LOW0 ≤ H < 0.3
MEDIUM0.3 ≤ H < 0.7
HIGH0.7 ≤ H ≤ 1
ข้อยำสำคัญ — เกณฑ์การแบ่งระดับนี้เป็นเกณฑ์เชิงแนวคิดสำหรับการแสดงผลและตีความของแบบจำลองในรายงานฉบับนี้เท่านั้น มิใช่มาตรฐานทางวิทยาศาสตร์ มาตรฐานอุตสาหกรรม หรือเกณฑ์ที่ได้รับการรับรองอย่างเป็นทางการแต่อย่างใด
07 / SYSTEMS VIEW

ทำไม Hallucination จึงเป็น Multi-Factor

ไม่มีปัจจัยใดเพียงตัวเดียวที่กำหนดความเสี่ยง — ตำแหน่งของเส้นโค้งแต่ละเส้นคือผลรวมของอิทธิพลจาก U, C, P, B พร้อมกัน

“ AI Hallucination ไม่ได้เกิดจากปัจจัยเดียว แต่เป็นผลจากหลายปัจจัยที่ทำงานร่วมกัน ”
08 / CALCULUS

Mathematical Insight

พฤติกรรมของฟังก์ชันโลจิสติกที่ Z มีค่าต่าง ๆ และอัตราการเปลี่ยนแปลงของความเสี่ยงเทียบกับ Z

Z มีค่าต่ำมาก → ความเสี่ยงเข้าใกล้ศูนย์

Z ใกล้ 0 → จุดกึ่งกลาง ความชันสูงสุด

Z มีค่าสูงมาก → ความเสี่ยงเข้าใกล้ค่าสูงสุด

อนุพันธ์ของ H เทียบกับ Z — มีค่าสูงสุด 0.25 เมื่อ H = 0.5 (จุดที่ความเสี่ยงไวต่อการเปลี่ยนแปลงมากที่สุด) และเข้าใกล้ 0 เมื่อ H เข้าใกล้ 0 หรือ 1
09 / ENGINEERING CONCEPT

Self-Verification & Feedback Loop

แนวคิดเชิงวิศวกรรมสำหรับลดความเสี่ยง Hallucination ด้วยการให้ AI ตรวจสอบคำตอบของตนเองก่อนส่งผลลัพธ์สุดท้าย อ้างอิงจากขั้นตอนการทดลองและแผนภาพประกอบรายงาน

01

Initial Prompt

เตรียมคำถามทดสอบและส่งคำถามให้ AI ประมวลผลและสร้างคำตอบเบื้องต้น (Draft Answer)

02

Self-Critique & Fact-Check

ป้อน Prompt พิเศษให้ AI ตรวจสอบคำตอบของตัวเอง เทียบเคียงกับบริบทแหล่งอ้างอิงและข้อกำหนดของ Prompt

03

Revision

หากผลตรวจสอบไม่ผ่านเกณฑ์ AI จะแก้ไขคำตอบหรือระบุขอบเขตความเสี่ยงที่ยังคงเหลืออยู่ แล้ววนกลับไปตรวจซ้ำ

04

Final Output Validation

เมื่อผ่านเกณฑ์ประเมินแล้ว จึงบันทึกคำตอบสุดท้ายและรวบรวม Feedback เพื่อปรับปรุงคุณภาพ Prompt และบริบทในรอบถัดไป

หมายเหตุสำคัญ — เอกสารประกอบอีกฉบับ (Decoding AI Hallucination) มีการยกตัวอย่างตัวเลขเชิงภาพประกอบ เช่น อัตราความผิดพลาดลดลงจาก ~30% เหลือ ~12% หลังผ่านกระบวนการ Self-Verification ตัวเลขดังกล่าว เป็นภาพประกอบแนวคิดจากเอกสารอีกฉบับหนึ่ง ไม่ใช่ผลการทดลองจริงของแบบจำลองทางคณิตศาสตร์ในรายงานนี้ และไม่มีการยืนยันว่าเป็นการทดลองชุดเดียวกัน จึงนำมาแสดงเพื่อประกอบแนวคิดเท่านั้น ดูไฟล์ต้นฉบับได้ที่ส่วน Sources
10 / SCOPE

ข้อจำกัดของแบบจำลอง

01 ค่าพารามิเตอร์ a, b, c, d และค่าคงที่ k เป็นค่าที่กำหนดขึ้นเพื่อการสาธิตและจำลองพฤติกรรมของแบบจำลองเท่านั้น
02 ค่าดังกล่าวไม่ใช่ข้อมูลที่ได้จากการฝึกฝน (Training) หรือการประเมินผลจริงของระบบ AI ใด ๆ
03 แบบจำลองนี้ไม่สามารถนำไปใช้ทำนายความเสี่ยง Hallucination ที่แท้จริงของแบบจำลองปัญญาประดิษฐ์โมเดลใดโมเดลหนึ่งได้
04 ระบบ AI จริงมีปัจจัยที่เกี่ยวข้องอีกจำนวนมาก เช่น สถาปัตยกรรม วิธีการฝึกฝน คุณภาพข้อมูลฝึก และกลไกการถอดรหัส ซึ่งแบบจำลองนี้ไม่ได้ครอบคลุม
05 วัตถุประสงค์หลักคือการอธิบายความสัมพันธ์เชิงแนวคิดระหว่างปัจจัยต่าง ๆ กับความเสี่ยงของ Hallucination มิใช่เครื่องมือวัดผลเชิงปริมาณที่แม่นยำ
11 / CONCLUSION

สรุป

ผลจากการวิเคราะห์กราฟทั้ง 4 กรณีแสดงให้เห็นอย่างชัดเจนว่าความเสี่ยงของ Hallucination มิได้ถูกกำหนดโดยปัจจัยใดปัจจัยหนึ่งเพียงลำพัง หากแต่เป็นผลรวมของปัจจัยหลายด้านที่ทำงานร่วมกันอย่างซับซ้อน ในเชิงคณิตศาสตร์ คุณสมบัติของฟังก์ชันโลจิสติกและอนุพันธ์ของมัน ช่วยอธิบายว่าความเสี่ยงจะไวต่อการเปลี่ยนแปลงมากที่สุดในช่วงความเสี่ยงระดับปานกลาง ซึ่งมีนัยสำคัญเชิงแนวคิดต่อการออกแบบมาตรการลดความเสี่ยง เช่น การพัฒนาคุณภาพของ Prompt หรือการเพิ่มบริบทที่เกี่ยวข้อง แบบจำลองนี้เป็นเครื่องมือเชิงแนวคิดเพื่อสนับสนุนความเข้าใจเท่านั้น มิใช่มาตรวัดทางวิทยาศาสตร์ที่ผ่านการพิสูจน์หรือรับรองจากการทดลองจริง
